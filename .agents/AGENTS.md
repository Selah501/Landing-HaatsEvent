# 🤖 하츠 충남대리점 프로젝트 AI 핵심 규칙 (System Prompt)

이 파일은 Antigravity(AI)가 대화를 시작할 때나 새로운 태스크를 계획할 때 **자동으로 가장 먼저 읽고 숙지하는 프로젝트 규칙(Project Rule)**입니다. 이 프로젝트 내에서는 대표님이 매번 지시하지 않아도 AI는 항상 이 규칙을 따릅니다.

## 1. 마스터 문서 강제 참조 (Mandatory Context Check)
새로운 대화창이 열리거나 새로운 기능 개발을 요구받을 때, 코드를 작성하거나 계획을 세우기 **전에 반드시 아래 세 가지 문서를 먼저 읽고 시작하십시오.**
- `c:\dev\전단지이벤트\landing\MASTER_PLAN.md`
- `c:\dev\전단지이벤트\HISTORY_AND_ROADMAP.md`
- `c:\dev\전단지이벤트\temp\Researcher_Input_Required.md`

## 2. 모순 및 충돌 사전 경고 (Conflict Prevention)
대표님의 새로운 요구사항이 위 마스터 문서들에 명시된 로드맵, 기존 구조, 또는 비즈니스 수익 모델과 충돌하거나 모순된다고 판단될 경우, **코딩을 시작하지 말고 즉시 대표님께 모순점을 보고하고 대안(별도 프로젝트화 등)을 묻거나 제안**하십시오.

## 3. 현장 실무 최우선 원칙
모든 개발은 '1인 기업의 현장 실무(장갑 낀 상태의 조작, 이동 중 통화 등)'를 최우선으로 고려해야 하며, 예외 상황(DB에 없는 부품 사용 등)을 반드시 뚫고 지나갈 수 있는 우회로(Fallback 텍스트 입력)를 마련해야 합니다.
