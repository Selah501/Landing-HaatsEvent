# 💡 펜딩(보류) 아이디어 및 향후 개발 과제 (Pending Ideas)

대화 중 당장 개발하지 않기로 결정되었으나 향후 구현이 필요한 기능과 아이디어를 체계적으로 기록하는 문서입니다.

## 1. 모바일 전용 CRM 조회 뷰 구축
- **발의일:** 2026-08-07
- **목적:** 외부 이동 중에도 스마트폰으로 전체 통화 이력을 신속하게 확인하고 결재 처리하기 위함.
- **보류 사유:** 현재 노션 연동은 모바일 가로 스크롤 문제가 있고, PC 백오피스(`admin.html`) 통합을 우선시함.
- **구현 아이디어:** Firebase 데이터를 기반으로 모바일 화면(Viewport)에 꽉 차는 세로형 전용 UI 탭(예: `mobile_crm.html`)을 신속 개발.

## 2. 노션(Notion) 마스터 고객 DB 연동
- **발의일:** 2026-08-07
- **목적:** 통화 요약 결재가 완료된 리드를 노션의 고객 마스터 DB로 전송하여 장기 관리.
- **보류 사유:** 모바일 뷰어 문제 및 현재 Firebase 내 통합 관리가 더 시급함.
- **구현 아이디어:** `crm_daemon.py`에서 Firebase 업로드 성공 시 Notion API를 호출하여 '전화번호'를 기준으로 그룹화(Group by) 가능한 구조로 데이터 전송.
