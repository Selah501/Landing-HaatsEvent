# [2026-09-03] 관리자 페이지 매뉴얼 통합 뷰어 및 동기화 스크립트 구축

## 🎯 주요 목표
- 흩어져 있는 사용자 매뉴얼(`.agents/manuals/*.md`) 및 히스토리/로드맵 문서를 웹 상에서 열람할 수 있도록 통합 뷰어 구축
- 특정 키워드로 문서를 쉽게 찾을 수 있는 검색 기능 제공
- 문서 첫 줄에 **최신 수정일(Latest Date)** 을 자동 삽입하여, AI 모델과 사용자가 신구 기능, 기능 삭제 등을 연계하여 정확하게 추적할 수 있는 확신 제공

## 🛠 구현 내용
1. **GNB(통합 내비게이션) 업데이트**
   - `landing/public/auth.js` 파일의 `renderAdminNav` 함수에 `📖 매뉴얼` 버튼을 신규 추가하여, 클릭 시 `manual.html`로 라우팅되도록 개선함.
   
2. **통합 뷰어 페이지 (`manual.html`) 신설**
   - **UI**: 좌측엔 카테고리별 목차와 검색창(사이드바)을, 우측엔 선택된 마크다운을 렌더링하는 본문 영역 배치.
   - **라이브러리**: `marked.js`를 이용해 마크다운 포맷팅 및 이미지(img) 태그를 깔끔하게 HTML로 변환하여 렌더링.
   - **사용자 경험**: "릴리스 노트 및 업데이트 로드맵"(`HISTORY_AND_ROADMAP.md`)을 진입 시 기본(default)으로 로드되도록 설정.

3. **자동화 스크립트 (`sync_manuals.js`) 구축**
   - 로컬 `.agents/manuals` 내부의 문서를 스캔하여 `landing/public/data/manual_data.json` 포맷으로 변환하는 Node.js 스크립트 작성.
   - **데이터 무결성(Timestamp)**: 스크립트 실행 시 파일의 마지막 수정 시간(`mtime`)을 감지하여, JSON 생성 시 본문 텍스트 최상단에 `> **Latest Date (최신 수정일): YYYY-MM-DD HH:MM**` 형태의 메타 정보를 강제 주입함.

## 🚀 배포 사항
- 로컬에서 `node sync_manuals.js`를 실행하여 JSON 데이터 생성.
- `firebase deploy --only hosting`을 통해 라이브 서버(flyer-event-page-2026.web.app) 적용 완료.
