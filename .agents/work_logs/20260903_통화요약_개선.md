# 🎯 워크스루: 미확정 리드 팔로업 보드 (마스터 표 대수술 완료)

대표님께서 기획해주신 **"Inbox(요약 카드)와 Follow-up 보드(테이블)의 완벽한 분리"** 작업이 라이브 서버에 100% 적용 완료되었습니다.

## 1. 🧹 확정 예약건과 미확정 리드 완벽 분리
- 이제 테이블에는 캘린더에 꽂힌 **'확정 예약건(`reservations`)'이 절대 나타나지 않습니다.**
- 오직 웹(QR) 신규 문의, 상담 리드, 보류 건들만 모여 있는 순수한 **`🎯 미확정 리드 팔로업 보드`**로 완벽하게 역할이 정리되었습니다.

## 2. 🎛️ 테이블 버튼 단일화 및 상세 모달 통합
- 기존 마스터 표에 지저분하게 널려 있던 버튼들(요약보기, 예약수정, 강제삭제 등)을 모두 제거했습니다.
- 오직 **`[🔍 상세 보기]`** 버튼 하나로 통일하여 가독성을 극대화했습니다.
- 해당 버튼을 누르면 고객 정보, 누적된 상담 히스토리 메모를 한눈에 볼 수 있는 **'상세 관리 모달창'**이 뜹니다.
- 모달창 안에서 **[💾 메모 저장]**, **[🗓️ 시공 예약]**, **[⏳ 보류]**, **[🗑️ 삭제]**의 강력한 4가지 액션을 원스톱으로 처리할 수 있습니다.

## 3. 🔃 컬럼별 원클릭 정렬(Sorting) 기능
- 테이블의 헤더(연락처/고객명, 신청내용, 상태/일시)를 **클릭할 때마다 오름차순/내림차순으로 즉시 정렬**됩니다.
- "최근에 들어온 문의부터 보기", "고객 이름 가나다순으로 보기" 등이 가능해져 수십 명의 리드도 쉽게 추적할 수 있습니다.

> [!TIP]
> 이제 전화가 오면 좌측 카드(Inbox)에서 즉시 처리하시고, 남은 리드들은 우측 테이블(팔로업 보드)에서 천천히 관리하시면 됩니다. 모든 흐름이 대표님 머릿속 구상과 정확하게 일치하게 되었습니다!


## 업무 흐름(Workflow) 가이드 및 버튼 설명

### 1. 업무 흐름 요약
통화를 마친 후 AI가 요약해 주는 **최초 카드**는 '미처리 수신함(Inbox)' 역할을 하며, 여기서 방향을 결정하여 카드를 쳐내는 것이 목적입니다(Zero Inbox).
이후 당장 예약이 안 된 건들은 **상담/보류 팔로업 보드**로 넘어가 지속적인 영업(팔로업) 관리를 받습니다.

### 2. 최초 카드 (Inbox) 버튼의 역할
- **[고객시공 예약]:** 당일 즉시 달력으로 예약을 확정짓고 카드를 지웁니다.
- **[💬 기존상담 추가]:** (자동) 같은 번호로 또 전화가 왔을 때 누르면, AI 요약 내용이 기존 카드 메모 최하단에 자동으로 이어 붙습니다.
- **[상담 리드등록]:** 아직 확정되지 않아 며칠 뒤 다시 통화해야 할 고객을 우측 팔로업 보드로 넘깁니다.
- **[보류]:** 스팸은 아니지만 당장 처리하기 애매한 건을 팔로업 보드로 넘깁니다.
- **[삭제]:** 스팸이나 단순 오과금 전화 등을 즉시 삭제합니다.

### 3. 상세 모달 (팔로업 보드) 버튼의 역할
팔로업 보드의 목적은 끈질긴 영업을 통해 최종적으로 예약을 따내는 것입니다.
- **[💾 메모 저장]:** (수동) 추가 통화를 통해 얻어낸 정보를 대표님이 직접 타이핑하여 누적 저장(업데이트)합니다.
- **[⏳ 보류]:** 당장 처리할 수 없거나 '다음 주에 연락 달라'는 등의 상태일 때, 노란색 [보류됨] 뱃지를 달아 보드에 계속 남겨둡니다.
- **[🗓️ 설치예약]:** 반복된 통화 끝에 드디어 예약이 성사되었을 때, 캘린더에 일정을 등록하고 보드에서 졸업(제거)시킵니다.
- **[🗑️ 삭제]:** 다른 업체에서 시공했거나 영업이 실패했을 때 과감히 지워버립니다.

### 4. 상태 뱃지 분류
- 🔘 **[대기중] (회색):** 웹(QR) 접수 건이나 최초 카드에서 갓 넘어온 일반 잠재 고객.
- 🟡 **[보류됨] (노란색):** 상세 모달에서 [⏳ 보류] 버튼을 눌러 명시적으로 대기시켜둔 악성/장기 대기 고객.
