# 🎉 [대화창 2] UI 통폐합 및 작업지시서 연동 완료

대표님의 기획 철학(로직 분리 유지 + UI 단일화)에 따라, 기존의 지저분한 UI를 모두 정리하고 새로운 상품 마스터 스키마를 작업지시서와 완벽히 연동했습니다.

## 🛠 수정된 주요 기능

### 1. `admin.html` 어설픈 탭 1 폭파 (UI/UX 최적화)
- 기존에 어중간하게 남아있던 **'1. 상품 마스터 관리' 탭을 뷰어로 남기지 않고 UI에서 완전히 제거**했습니다. 
- 접속 시 바로 '현장별 이벤트 관리'가 기본(active) 탭으로 뜹니다.
- 상품 관리가 필요하실 때는 기존처럼 상단의 **[📦 상품 마스터]** 버튼만 누르시면 매끄럽게 연결됩니다. (로직 분리 유지)

### 2. `admin_v2.html` (일일 작업지시서) 고도화 연동
- **`is_active` 필터 적용**: 현장에서 작업지시서를 작성할 때 제품을 검색하면, 이제 `product_master.html`에서 `취급(is_active)=true`로 설정된 상품만 정확히 노출됩니다.
- **영구 단가 스냅샷(`prices` 스키마) 연동**: 현장 기사님이 제품을 추가(addModalProduct)하고 저장(saveReport)하는 순간, 새로 개편된 구조의 `prices.purchase` (매입가)와 `prices.sell_total` (총판매가)를 가져옵니다. 그리고 이 값을 **Firebase `reservations` DB 안에 영구적으로 박제(Snapshot)하여 마진을 계산**하도록 로직을 성공적으로 업데이트했습니다.

- 라이브 서버에 반영하기 위해 `firebase deploy --only hosting`을 실행하여 성공적으로 배포를 마쳤습니다.
