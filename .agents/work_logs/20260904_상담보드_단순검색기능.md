# 2026-09-04 상담/보류 팔로업 보드 단순 검색기능 추가

## 작업 배경
- 탭 3의 상담/보류 팔로업 보드 (테이블형) 상단에 존재하던 '카테고리 선택' 필터가 불필요하다는 피드백.
- 복잡한 필터나 상세 보기 팝업 대신 연락처, 고객명, 내용을 바로 검색할 수 있는 "단순 검색" 기능 필요성 대두.
- 시공검색(admin_v2) 탭의 카드 뷰에서 사용하는 것과 동일한 직관적인 단순 텍스트 검색창으로 교체 요망.

## 변경 내용
- **`landing/public/admin.html` 수정:**
  1. `<select id="master-category-filter">` 및 관련 마크업 제거.
  2. 그 자리에 `<input type="text" id="consult-search-keyword">` (검색창), `단순 검색` 버튼, `초기화` 버튼 배치.
  3. 자바스크립트 전역에 `window.searchConsultations()` 함수 추가하여 검색어 세팅 후 `renderConsultations()`를 재호출하도록 연동.
  4. `renderConsultations()` 함수 내부 정렬 직전 단계에 텍스트 필터링 로직(`item.customer`, `item.phone`, `item.content`, `item.adminMemo`를 대상으로 `includes` 검사) 추가.

## 테스트 및 배포
- Firebase Hosting 배포 완료 (`firebase deploy --only hosting`).
- 테이블에 표시되는 약 30여 개의 데이터를 4가지 주요 필드를 타겟으로 실시간 필터링 확인 완료.
