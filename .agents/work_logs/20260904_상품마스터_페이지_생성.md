# 상품 마스터 전용 페이지 신설 작업 워크스루

## 🎯 작업 요약
* **일시**: 2026-09-04
* **목적**: 기존 혼용되던 상품 DB 관리를 "상품 마스터 공장"으로 독립시켜 아키텍처 논리 모순을 해결함 (1차 대화창 작업 완료)

## 🛠 주요 변경 사항

### 1. Supabase Schema Migration 쿼리 작성 완료
* `is_active` (boolean): 활성/비활성 여부
* `is_set` (boolean): 세트 상품 여부
* `set_components` (jsonb): 세트 구성품 목록
* `prices` (jsonb): 다중 가격 데이터(매입가, 제품가, 설치비, 총합)
* `detail_urls` (jsonb): 상세페이지 링크
* **SQL 쿼리문은 `landing/supabase_schema_update.sql` 파일에 저장됨** (대표님이 브라우저에서 실행하셔야 함)

### 2. `auth.js` GNB 네비게이션 추가
* 기존 GNB 메뉴에 **[📦 상품 마스터]** 메뉴를 신규 추가하여, 어디서든 이 페이지로 바로 이동할 수 있도록 동선 구축 완료.

### 3. `product_master.html` 독립 페이지 구축 완료
* **UI/UX**: 기존 다크 테마(Admin V2)와 완벽히 호환되는 모던한 인터페이스.
* **마스터 데이터 제어**: `is_active` 스위치 원클릭 토글을 통해 상품의 노출 여부를 직관적으로 관리.
* **세트 조립 기능**: 여러 단품을 조합하여 새로운 세트 상품을 구성하고, 그에 따른 '매입가'가 **실시간 자동 합산**되도록 로직 완벽 구현.
* **모달 폼 고도화**: 다중 단가(`purchase`, `sell_product`, `sell_install`, `sell_total`) 입력 및 링크 배열(`detail_urls`)을 폼으로 구성하여 깔끔하게 Supabase에 저장하도록 JSON 구조 매핑.
