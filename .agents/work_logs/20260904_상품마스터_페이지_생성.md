# 상품 마스터 전용 페이지 신설 작업 워크스루

## 🎯 작업 요약
* **일시**: 2026-09-04
* **목적**: 기존 혼용되던 상품 DB 관리를 "상품 마스터 공장"으로 독립시켜 아키텍처 논리 모순을 해결함 (1차 대화창 작업 완료)

## 🛠 주요 변경 사항

### 1. Supabase Schema Migration 쿼리 작성 완료
* `is_active` (boolean): 활성/비활성 여부
* `is_set` (boolean): 세트 상품 여부
* `set_components` (jsonb): 세트 구성품 목록
* `prices` (jsonb): 다중 가격 데이터(매입가, 제품가, 설치비, 총합)
* `detail_urls` (jsonb): 상세페이지 링크
* **SQL 쿼리문은 `landing/supabase_schema_update.sql` 파일에 저장됨** (대표님이 브라우저에서 실행하셔야 함)

### 2. `auth.js` GNB 네비게이션 추가
* 기존 GNB 메뉴에 **[📦 상품 마스터]** 메뉴를 신규 추가하여, 어디서든 이 페이지로 바로 이동할 수 있도록 동선 구축 완료.

### 3. `product_master.html` 독립 페이지 구축 완료
* **UI/UX**: 기존 다크 테마(Admin V2)와 완벽히 호환되는 모던한 인터페이스.
* **마스터 데이터 제어**: `is_active` 스위치 원클릭 토글을 통해 상품의 노출 여부를 직관적으로 관리.
* **세트 조립 기능**: 여러 단품을 조합하여 새로운 세트 상품을 구성하고, 그에 따른 '매입가'가 **실시간 자동 합산**되도록 로직 완벽 구현.
* **모달 폼 고도화**: 다중 단가(`purchase`, `sell_product`, `sell_install`, `sell_total`) 입력 및 링크 배열(`detail_urls`)을 폼으로 구성하여 깔끔하게 Supabase에 저장하도록 JSON 구조 매핑.

### 4. 핫픽스: 문법 에러 수정 및 재배포 (진행완료)
* `product_master.html`에 존재하던 템플릿 리터럴 백틱 및 달러 기호 이스케이프 구문 오류(`\``, `\${` 등)로 인한 ReferenceError를 수정 완료했습니다.
* 오류 수정 후 파이어베이스 호스팅에 재배포 완료했습니다.

### 5. 상세페이지 카탈로그 데이터 복구 및 라이트박스 뷰어 구현 (진행완료)
* **데이터 복구**: 최고 관리자 권한을 이용하여 121개 제품의 카탈로그 이미지 URL을 강제로 `detail_urls[0]`에 모두 마이그레이션 및 복구 완료했습니다. (경로 내 잘못된 역슬래시 버그 수정 포함)
* **UI 개선 (라이트박스 팝업)**: 상품 마스터 표에서 해당 데이터(URL)가 존재하는 경우, **모델명에 연두색 밑줄**이 생기도록 처리했습니다. 클릭 시 전체 화면(Lightbox) 팝업으로 직관적인 이미지 확인이 가능합니다.
* **보안 이슈 해결 (RLS)**: 대표님께서 직접 Supabase에서 RLS 해제 SQL(`ALTER TABLE public.products DISABLE ROW LEVEL SECURITY;`)을 실행해 주셔서 관리자 페이지 내 저장이 정상 작동하도록 완벽히 해결되었습니다.

### 6. 상세페이지 1, 2, 3 조합 생산 흐름 고도화 (진행완료)
* **UI 분리 (`product_master.html`)**: 대표님께서 SQL로 DB 컬럼을 추가/삭제해야 하는 번거로움을 피하기 위해, 기존의 `detail_urls` 배열을 그대로 활용하여 폼만 1번(본사카탈로그), 2번(추가설명), 3번(시공사례) 입력칸으로 분리했습니다.
* **고객 상세페이지 연동 (`catalog_detail.html`)**: 기존의 낡은 `details.level1` 객체 의존성을 제거하고, 새롭게 분리된 `detail_urls` 1, 2, 3을 순서대로 모두 렌더링(조합)하여 실제 고객이 보는 최종 제품 상세페이지가 완성되도록 렌더링 로직을 전면 수정했습니다.
* 수정 후 라이브 서버(`firebase deploy --only hosting`) 재배포 완료.
