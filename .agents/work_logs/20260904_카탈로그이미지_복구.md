## 🛠 작업 내용

### 문제 원인
- 이전 AI가 `migrate_all_catalogs.mjs`를 실행하여 `data.json`, `extracted_all.json` 등 레거시 JSON의 존재하지 않는 경로(`/images/catalog/...`)를 DB에 밀어넣음
- 실제 정밀 추출 이미지는 `public/catalog_images/[모델명].png` 형태로 308개 완벽 존재

### 해결 방법
`landing/fix_catalog_images.mjs` 스크립트 신규 작성 및 실행

**매칭 알고리즘 (5단계 방어 로직)**:
1. 모델명 직접 매칭 (대소문자 무시, 공백 제거)
2. 하이픈(-) 제거 후 재매칭
3. `HZ-` / `FC-` / `WS-` 등 브랜드 접두사 제거 후 재매칭
4. 복합 모델명 (콤마/슬래시 구분) → 첫 번째 모델로 시도
5. 매칭 실패 시: `detail_urls[0] = ''` (쓰레기 URL 제거, [1][2]는 보존)
