# 🎉 [대화창 4] 현장등록 제품검색(UI) 대통합 완료

대표님께서 `admin_v2.html` (작업지시서) 및 `erp.html` (장부)에 적용하셨던 실시간 제품 텍스트 검색 컴포넌트를 `admin.html`의 **신규/기존 현장등록 모달**에도 성공적으로 이식 및 대통합했습니다.

## 🛠 수정된 주요 기능

### 1. `admin.html` 현장등록 모달 제품검색 고도화
- 기존: 카테고리 그룹화된 `Select2` 방식 사용. (검색이 제한적이고 신규 현장 등록 시 모달 Focus 충돌 등으로 검색 텍스트 입력이 불가능하거나 UX가 떨어지던 문제 존재)
- 변경: 상품명, 모델명, 마케팅 메모까지 한 번에 실시간으로 검색할 수 있는 커스텀 텍스트 검색 컴포넌트로 완전히 교체.
- 메인 상품과 부가 상품 모두 각각 독립적인 검색 인터페이스를 통해 최대 20개의 검색 결과를 실시간(onkeyup)으로 렌더링하고, 클릭 시 직관적으로 입력되도록 개선했습니다.

### 2. 기존 현장 데이터 100% 무결성 보존 (안전장치)
- 새 컴포넌트를 이식하는 과정에서 편집용 임시 배열인 `window._editMainProds`와 `window._editAddonProds` 구조를 기존(Select2 시점)과 완벽하게 동일하게 유지했습니다.
- 따라서 기존에 등록해둔 현장들의 단가(`customText`), 상세링크(`customLink`), 상품ID 정보 등은 단 1byte의 유실도 없이 그대로 보존되고 정상적으로 렌더링되며 저장됩니다.
