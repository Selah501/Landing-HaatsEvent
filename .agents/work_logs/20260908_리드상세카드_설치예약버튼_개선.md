# 리드 상세 카드 설치예약 버튼 동작 개선

## 작업 배경
- 기존 `admin.html`의 🎯 상담/보류 팔로업 보드에서 리드의 [상세보기] 카드를 열고 **[🗓️ 설치예약]** 버튼을 누르면 새 탭으로 V2 설치예약시스템(`reservation_v2.html`)이 열리는 동작을 수행함.
- 이로 인해 전화번호와 고객명만 쿼리파라미터로 넘어가고, 상세 모달에 있던 구체적인 품목(items)과 메모가 연동되지 않아 관리자가 고객 정보를 처음부터 다시 기입해야 하는 치명적인 불편함이 존재했음.
- 반면 Inbox(통화 요약 실시간 카드)의 **[🗓️ 고객시공 예약]** 버튼은 Unified Modal(예약 팝업)을 띄워서 고객의 모든 정보가 자동 채워진 상태로 달력 일정을 잡을 수 있는 편리한 UI를 갖추고 있었음.

## 작업 내용
1. `admin.html`의 `window.confirmDetailCardReservation` 함수 구조 변경
   - 변경 전: `window.open('reservation_v2.html?...')`를 통해 새 탭으로 리다이렉트
   - 변경 후: 리드 카드의 DOM 엘리먼트(`dcm-customer`, `dcm-phone`, `dcm-content`, `dcm-memo`)에서 값을 추출한 후, Inbox 카드와 동일하게 `window.openUnifiedModal()`을 호출하도록 변경.
2. 이제 리드 상세 카드에서 [설치예약]을 누르면, 리드 내용이 그대로 예약 팝업창(Unified Modal)에 복사되어 노출되며, 바로 날짜와 시간을 지정해 작업지시서에 등록(Save)할 수 있음.

## 효과
- 더 이상 V2 시스템 새 탭으로 넘어가 빈 양식을 채울 필요가 없음.
- 통화 요약 리드를 끈질기게 추적(Follow-up)하다가 예약이 확정되는 즉시, 모든 정보 유실 없이 1초 만에 달력에 등록할 수 있는 완벽한 CRM 흐름 완성.
- 코드 간소화 및 예약 등록 UI 통합(Unified Modal) 원칙 준수.
