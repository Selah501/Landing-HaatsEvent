# 2026-09-08 작업지시서 원가/재고 관리 및 AI 음성 매입/지출 대기열 연동

## 1. 개요
* 작업지시서(`admin_v2.html`)와 재무장부(`erp.html`) 간의 데이터 단절 문제를 해결하기 위해 **원가 기록** 및 **재고 자동차감** 로직을 연동.
* AI 음성 통화 분석 시스템(`processCallRecording.js`)을 확장하여 '매입/지출' 카테고리를 분류하고, 이를 `erp.html` 내의 **AI 매입/지출 대기열 (Inbox)**로 전달하는 파이프라인을 구축.

## 2. 주요 변경 사항

### A. UX 일관성 개선 (검색기 통일)
* `admin_v2.html` 작업지시서 및 `erp.html` 장부 모달 내의 구형 2단계(카테고리->상품) 드롭다운 선택기를 제거.
* `product_master.html`에서 사용되는 **실시간 텍스트 검색기** 컴포넌트로 일괄 교체하여, 직관적이고 빠른 제품 검색 지원.

### B. 일일보고서 누락 방지 대시보드 알림
* `erp.html` 접속 시, 과거 날짜 중 결재(저장)가 누락된 미완료 일일보고서(`daily_reports` 미존재, 단 작업완료된 예약은 존재)를 자동 체크.
* 대시보드 최상단에 🚨 알림 배너를 띄워 관리자에게 즉각적인 처리를 유도.

### C. 원가(COGS) 저장 및 재고 자동 차감 로직 구현
* `admin_v2.html`에서 '보고서 저장' 시, 투입된 상품들의 `costPrice`(매입가) 합산액을 `totalCost`로 산출.
* 이를 `ledger` (장부) 노드에 '시공 수입'과 함께 저장.
* 동시에 `inventory_counts` (재고) 노드에서 사용된 상품 수량만큼 자동 차감 처리.
* `erp.html`의 원장 뷰에서 '시공 수입' 항목 클릭 혹은 호버 시 원가(매입가)와 투입 자재를 시각적으로 노출하여 마진 파악 용이.

### D. AI 음성 기반 매입/지출 자동화 (Inbox)
* **Cloud Functions (`processCallRecording.js`)**: 기존 예약/상담 외에 '매입' 또는 '경비 지출' 관련 내용 수신 시, 이를 분리 파싱하여 `crm_pending` 큐에 `category: '매입/지출'`로 푸시.
* **ERP Frontend (`erp.html`)**: 장부 탭 진입 시, 해당 `crm_pending` 대기열을 읽어 **AI 매입/지출 음성 대기열 (Inbox)** 영역에 렌더링.
* 관리자가 '장부에 기입하기' 버튼 클릭 시, 수동 장부 모달이 자동으로 채워지며, 저장 완료 시 큐(Inbox)에서 해당 항목 자동 삭제.

### E. 거래처 원장 요약(Summary) 뷰 제공
* `erp.html`의 거래처 원장 탭에서 특정 거래처를 선택하기 전, 등록된 **모든 거래처의 전기 이월, 당기 매입, 당기 지급, 미지급 잔액**을 한눈에 볼 수 있는 요약 테이블 뷰 구현.
