# 🚀 작업 요약: 통화 요약 데몬 사전 경고 모니터링 적용 (2026-09-08)

## 📌 주요 변경 사항
1. **데몬 생존 신고 (Heartbeat) 로직 추가**
   - `crm_daemon.py`에서 약 8시간 간격으로 Firebase RTDB(`system/daemon_status`)에 `status: "OK"`와 `last_heartbeat` 타임스탬프를 전송하도록 수정했습니다.
   - 불필요한 트래픽 낭비를 막기 위해 하루 3회(8시간 주기)로 빈도를 낮추었습니다.

2. **에러 직통 보고망 개설**
   - `crm_shared.py`의 `process_audio_file` 함수 내 예외 처리 구문을 확장했습니다.
   - API 키 오류(400), 한도 초과(429), 기타 파이썬 크래시 등 파일 처리 중 에러가 발생하면 즉시 RTDB에 `status: "ERROR"`와 상세 에러 메시지를 기록합니다.

3. **관리자 페이지(admin.html) 능동적 감시 UI 적용**
   - `admin.html` 하단에 RTDB의 `system/daemon_status`를 실시간으로 구독하는 자바스크립트를 추가했습니다.
   - **강제 팝업**: 클라우드에 `ERROR` 상태가 감지되면, 대표님이 페이지를 열고 계실 때 즉시 중앙에 지워지지 않는 붉은색 에러 팝업(SweetAlert)을 띄웁니다.
   - **은은한 경고**: 데몬의 마지막 생존 신고(`last_heartbeat`)가 24시간을 초과하여 지연된 경우, 우측 상단에 노란색 `⚠️ PC 연결 끊김 의심` 뱃지를 띄워 PC 전원이나 프로그램 종료 상태를 직관적으로 인지할 수 있게 했습니다.

## ✅ 배포 상태
- 프론트엔드(`admin.html`) 수정 후 `firebase deploy --only hosting` 을 통해 라이브 서버 배포 완료되었습니다.
- 백그라운드에서 `crm_daemon.py` 프로세스를 최신 코드로 재시작하여 정상 가동 중입니다.
