# 현장명(동호수) 데이터 형식 일괄 개편

## 작업 배경
- 기존 AI 통화 요약 및 예약시스템(V2)은 현장명 형식이 `[지역] 아파트명 동호수` 또는 `동호수 [지역] 아파트명` 등으로 일관되지 않게 저장되는 경우가 있었음.
- 현업에서 대표님이 가장 직관적으로 인식하고 문자 발송 시 깔끔하게 노출되는 **`102동 2003호 효성해링턴플레이스 [내포]`** 형식으로 데이터 생성 구조를 전면 통합할 필요가 있었음.

## 작업 내용
1. **AI 통화 요약 프롬프트 튜닝 (`processCallRecording.js`, `crm_shared.py`)**
   - 현장명(site_info) 추출 시 AI에게 반드시 `[동/호수] [아파트명] [[지역명]]` 순서로 재조합하도록 명확한 지시문 추가.
   - 현장 정보가 전혀 없는 콜일 경우 방어 로직으로 `미확인현장 [미확인]` 기본값을 출력하도록 AI 프롬프트 갱신.
2. **V2 고객 예약 폼 디폴트 포맷팅 (`reservation_v2.html`)**
   - 고객이 직접 이벤트 링크로 접속할 때, 이벤트 제목(예: `[내포] 효성해링턴플레이스 아파트 공구`)에서 지역명(`[내포]`)을 정규식으로 안전하게 분리.
   - 고객이 기입한 `102동 2003호` 값 뒤에 `효성해링턴플레이스 [내포]`가 차례로 결합되도록 디폴트 텍스트(Apt) 설정 로직을 전면 수정.
   - 이로 인해 관리자가 AI로 수집한 리드나, 고객이 직접 접수한 예약이나 모두 **`102동 2003호 효성해링턴플레이스 [내포]`** 텍스트 형식으로 100% 동일하게 DB에 적재됨.

## 효과
- 데이터 정합성 완벽 확보.
- 관리자 달력이나 작업지시서에서 현장명을 볼 때 일관된 패턴으로 노출되어 가독성 대폭 상승.
- 알림 문자 템플릿 등에서도 어색함 없이 `102동 2003호 효성해링턴플레이스 [내포]` 형태로 자연스럽게 발송됨.
