# [2026-09-09] AI 상세페이지 자동 생성 기반 구축 및 워크플로우 인수인계서

## 📌 작업 개요
하츠 충남대리점 프로젝트의 상품 마스터 페이지 및 고객 랜딩 페이지에서, AI가 조립한 HTML(상세페이지)을 직접 저장하고 관리/노출하는 시스템 뼈대를 구축했습니다.

## 🛠 완료된 작업 (현재 코드 상태)

1. **DB 아키텍처 개편**
   - Supabase `products` 테이블에 `detail_pages` (JSONB) 컬럼 추가 완료.
   - *데이터 형식*: `[{ "id": "v1_...", "title": "버전명", "html": "...", "is_active": true }]`

2. **고객용 단일 뷰어 신설 (`landing/public/product.html`)**
   - `?id=xxx&version=yyy` 파라미터를 받아, 해당 상품의 특정 버전 HTML을 랜딩페이지에 렌더링하도록 구현. (버전 파라미터가 없으면 첫 번째 버전을 기본 렌더링).

3. **상품 마스터 어드민 UI 개편 (`landing/public/product_master.html`)**
   - 기존의 파편 이미지 입력창 명칭을 "제품 이미지 1~3"으로 변경하여 혼란 방지.
   - **[🤖 AI 상세페이지 (HTML 버전 보관함)]** 리스트 UI 신설.
   - 각 버전별로 `[👀 미리보기]` 및 `[🗑️ 삭제]` 기능 탑재 (활성화 스위치 제거 완료).

4. **전용 봇(Skill) 세팅 완료**
   - `.agents/skills/detail-page-maker/SKILL.md` 생성 완료.
   - 새 대화창에서 "상세페이지 만들어줘" 라고만 하면 즉각 AI가 해당 템플릿(4단계 레이아웃) 룰을 따르도록 설정됨.

5. **이벤트 랜딩 연결 (`index.html`)**
   - 모든 메인/서브 상품의 "자세히 보기" 버튼이 `product.html`로 연결되도록 기본 fallback 링크 로직 반영.

   - 새 대화창에서 **"상세페이지 만들어줘"** 를 입력하고 워크플로우(자료 제출 -> 초안 확인 -> 피드백 -> 승인/저장)를 실제 체감해 봅니다.
   - 테스트 제품: (예: HRH-90S 허리케인 등).

2. **어드민(Admin) 편의성 고도화 검토**
