# [2026-09-09] ERP 대시보드 실적 집계 발생주의 적용 및 필터 추가

## 주요 변경 사항
1. **ERP 대시보드 실적 필터 신설 (`erp.html`)**:
   - 기존에는 모든 과거 실적이 단순 합산되어 '월 누적 총 매출'로 표기되는 버그가 있었음.
   - 월간/분기/연간/직접지정/현장명(동호수) 검색을 지원하는 고도화된 필터링 UI 추가.

2. **순이익 계산 '발생주의' 도입**:
   - 기존의 '현금주의(당월 재고 매입액 전체 차감)' 방식은 실질적인 영업 마진을 왜곡함.
   - 실제 결제액(매출)에서 시공된 제품의 원가(매출원가)와 순수 기타 경비만 차감하도록 계산식을 개선하여, 재고량 변동과 무관하게 정확한 영업 순이익을 모니터링할 수 있도록 함.
   
3. **일일보고서 텍스트 렌더링 버그 수정 (`erp.html`)**:
   - `[object Object]`로 표시되던 시공품 텍스트를 `제품명 n개` 형식으로 정상 렌더링되도록 수정.

4. **작업지시서 '실제 마진' 로직 추가 (`admin_v2.html`)**:
   - 보고서 모달에서 상품마스터 기준 '예상 마진' 외에도, 사용자가 텍스트 인풋에 '실제 결제 금액'을 입력할 때마다 실시간으로 **'실제 순이익(결제액 - 매입가)'**을 계산하여 보여주도록 개선.
   - Firebase DB 저장 시 `actualMargin` 필드를 별도로 생성하여 영구 보존.
