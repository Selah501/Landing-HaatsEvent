# 2026-09-13 아파트 DB AI 사전분석 고도화 및 에러 해결

## 주요 작업 내역
1. **아파트 DB 항목 추가 (`apt_db.html`, `supabase_apt_schema.sql`)**
   - `준공년도` 및 `마진총액` 기둥(컬럼) 추가.
   - AI 분석 시 과거 시공 내역의 실마진을 합산하여 폼에 자동 입력되도록 로직 구현.
2. **AI 사전분석 기능 고도화 및 500 에러 해결**
   - **원인:** 기존 `gemini-pro-latest` 텍스트 전용 모델을 쓰다가 이미지 분석을 위해 `gemini-1.5-flash`로 교체하는 과정에서, 시공 사진 누적으로 인한 **서버 메모리 부족(OOM)** 현상 및 **최신 모델명 API 버전 불일치(404 에러)** 발생.
   - **해결:**
     - Firebase Cloud Function (`analyzeApartmentSpec`) 메모리를 256MB -> 1GB로 증설, 타임아웃 300초로 상향.
     - 최신 API 스펙에 맞춰 AI 두뇌를 현존 가장 빠르고 최신 모델인 `gemini-3.6-flash`로 완벽 교체.
3. **사진 누락 로직 개선**
   - **원인:** 기존 로직이 '오래된 순서대로' 5장을 자르다 보니, 최근에 시공한 주방 후드 사진이 AI 분석에서 누락됨.
   - **해결:** 시공 사진 배열(`mediaUrls`)에서 **가장 최근(최신) 시공 사진 10장**을 추출(`.slice(-10)`)하여 분석하도록 로직 역순 개선 및 허용 용량 확대.
4. **UI 편의성 개선 (`admin.html`)**
   - 모달 드래그 방지(user-select)를 강제로 풀다가 저장 버튼이 먹통이 되는 부작용 발생 -> 텍스트 인풋칸(`input[type=text]`)에만 선택을 허용하도록 CSS 정밀 롤백 및 재적용 완료.
