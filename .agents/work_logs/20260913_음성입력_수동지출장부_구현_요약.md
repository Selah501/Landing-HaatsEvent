# 20260913 장부 수동 등록 폼 Web Speech API (음성 입력) 구현 요약

## 🛠️ 작업 내역 요약
- **음성 입력 UI 추가:**
  - `erp.html`의 "장부 수동 등록" 팝업 상단에 `🎙️ 음성으로 채우기` 버튼을 신설했습니다.
  - 마이크 권한 요청 및 인식 상태(듣는 중, 분석 중, 인식 완료 등)를 시각적으로 보여주는 상태 알림 텍스트 영역을 추가했습니다.

- **브라우저 내장 Web Speech API 연동:**
  - 외부 API(Gemini 등) 호출 비용 없이 브라우저 자체 음성 엔진을 사용하여 즉각적으로 음성을 텍스트로 변환하도록 구현했습니다. (`window.SpeechRecognition` 활용)

- **자연어 파싱 로직 (JS 정규식) 자체 구현:**
  - 변환된 텍스트에서 금액, 결제 수단, 항목, 거래처를 자동으로 추출하여 폼을 세팅해 줍니다.
  - **금액 파싱:** "만오천원", "15,000원", "1만 5천원" 등 다양한 포맷의 음성 인식 결과를 정규식과 한국어 숫자 변환 함수(`parseKoreanNumber`)를 통해 정확한 숫자로 치환합니다.
  - **수입/지출 및 계좌:** "지출", "결제", "매입" 등의 키워드로 지출을 기본 세팅하며, "현금", "카드", "이체", "외상" 등의 단어를 감지해 계좌 드롭다운을 변경합니다.
  - **항목 자동 세팅:** "식대", "기름", "재고", "피스" 등의 실무 키워드를 기반으로 '경비' 또는 '현금매입(재고)' 카테고리로 자동 선택되도록 매핑했습니다.
  - **메모 및 거래처:** 말씀하신 내용 전체를 '적요(메모)' 칸에 일단 기록하여 잘못 인식된 경우 확인하기 쉽도록 하였고, 마스터에 등록된 거래처 이름이 언급되면 자동으로 거래처명에 세팅됩니다.

## ✅ 결과 확인
- 버튼을 누르고 **"오늘 철물점에서 피스 만오천원 현금결제했어"** 라고 말씀하시면, 금액(`15000`), 계좌(`현금`), 항목(`현금매입(재고)`), 거래처(`철물점`), 메모(`오늘 철물점에서...`)가 즉시 채워지는 것을 보실 수 있습니다.
- 빈 칸이나 잘못 인식된 부분만 수동으로 살짝 수정한 뒤 저장하시면 됩니다.
- Firebase Hosting 서버에 즉시 배포(`firebase deploy --only hosting`) 완료했습니다.
