# 20260913 일일보고서 순수익 발생주의 적용 요약

## 🛠️ 작업 내역 요약
- **발생주의 회계 적용 범위 확대:**
  - 기존에는 ERP 대시보드 상단(월 누적 총 매출 / 매출원가 / 순 이익)에만 발생주의(재고 매입액 제외, 매출원가 차감)가 적용되어 있었습니다.
  - 이를 "📝 현장 일일 보고서" 탭의 **일일 순수익 계산** 로직에도 동일하게 확대 적용했습니다.

- **`erp.html` 내 `loadDailyReport()` 함수 수정:**
  - **매출원가(`dailyCostOfGoodsSold`) 계산 추가:** 일일 시공 완료된 건(`usedProducts`)의 수량과 매입 단가(`costPrice`)를 찾아 합산하는 로직을 추가했습니다.
  - **순수 경비 필터링 적용:** 일일 지출액 중에서 재고 매입(현금매입(재고), 외상매입, 외상대금 결제)에 해당하는 건은 순수 경비(`dailyPureExpense`)에서 제외시켰습니다.
  - **순수익 공식 변경:** 기존 `매출액 - 지출액` 에서 `매출액 - 매출원가 - 순수경비` 로 변경하여 재고를 대량 매입한 날에도 정확한 당일 영업 마진을 확인할 수 있게 되었습니다.

- **UI 직관성 개선:**
  - 일일 보고서 하단의 라벨을 `💰 일일 순수익 (매출 - 지출):` 에서 `💰 일일 순수익 (매출 - 원가 - 순수경비):` 로 변경하여 대표님이 계산식을 명확하게 인지하실 수 있도록 조치했습니다.

## ✅ 결과 확인
- 당일 시공 시 사용된 자재 원가와 재고 매입 이외의 지출액(식대/유류비 등)만이 차감되어, **일일보고서 결재 시 정확한 발생주의 마진**이 기록됩니다.
- Firebase Hosting 서버에 즉시 배포(`firebase deploy --only hosting`) 완료했습니다.
