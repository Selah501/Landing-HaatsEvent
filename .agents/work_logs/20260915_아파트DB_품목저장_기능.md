# 🏢 아파트 DB 교체 품목 및 자료 첨부 기능 추가 (2026-09-15)

## 1. 개요
기존 `apt_db.html` 페이지에 아파트 현장별로 **'교체 품목 및 관련 영업자료(문서/이미지)'**를 최대 5장까지 첨부하고 체계적으로 관리할 수 있는 섹션을 신설하였습니다. 또한, Firebase Storage의 접근 권한(`storage.rules`)을 수정하여 새로 추가된 이미지 업로드 기능이 정상 작동하도록 조치했습니다.

## 2. 주요 작업 내용

### 2-1. UI 및 로직 추가 (`apt_db.html`)
- **UI 렌더링**: 아파트 세부 정보 모달 내에 `교체 품목 및 자료 (문서/이미지)`를 관리하는 동적 테이블 뷰를 추가했습니다.
  - 관리 필드: `교체전 제품`, `교체제품`, `구분(카테고리)`, `특징`, `이미지/문서`, `특기사항`
  - 기능: 행 추가/삭제, 항목 텍스트 검색, 기준별 오름차순 정렬 기능
- **이미지 업로드 및 뷰어**:
  - `firebase-storage.js` 모듈을 연동하여 파일(최대 5장) 업로드 기능 구현.
  - 업로드된 이미지는 썸네일 형태로 미리보기가 제공되며, 클릭 시 화면 전체에 모달(Lightbox) 형태로 크게 확대됩니다.
- **카테고리(구분) 커스텀 에디터**:
  - `system/apt_categories` (Firebase RTDB)에 카테고리 목록을 저장하여 영구 보존.
  - 사용자가 [⚙️ 구분 관리] 버튼을 눌러 모달 창에서 새로운 구분을 추가하거나 기존 구분을 자유롭게 삭제할 수 있도록 구현했습니다.

### 2-2. DB 스키마 업데이트
- **Supabase**: `apartment_specs` 테이블에 교체 품목 배열 데이터를 유연하게 저장할 수 있도록 `replacement_items` (JSONB) 컬럼을 추가했습니다.
- **실행 스크립트**: Node/Python 등을 활용한 ALTER TABLE 쿼리를 직접 실행하여 DB를 무중단 마이그레이션했습니다.

### 2-3. Firebase 보안 규칙 수정 및 배포
- **원인**: 초기 업로드 시 403 (권한 없음) 에러 발생. `storage.rules`에 `/apt_db/` 폴더에 대한 쓰기/읽기 권한이 정의되어 있지 않았습니다.
- **조치**: `landing/storage.rules` 파일 내에 `match /apt_db/{allPaths=**}` 권한 허용 규칙을 삽입하고, `firebase deploy --only storage,hosting`을 통해 서버에 즉시 적용 완료했습니다.
