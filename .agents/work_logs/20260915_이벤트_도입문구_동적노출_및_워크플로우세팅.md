# 🚀 현장별 도입 문구 동적 노출 시스템 구축 완료

대표님의 기획 의도에 맞춰, **"QR 인입 시 현장 리스트 노출 ➡️ 고객이 본인의 현장을 클릭 시, 해당 현장만의 고유한 도입 문구 노출"** 구조로 시스템을 전면 개편했습니다.

## 🛠️ 주요 변경 사항

### 1. 관리자 페이지 (`admin.html`) 입력 기능 추가
- 이벤트 현장 등록/수정 모달창에 **[현장별 도입 문구]** 입력 필드를 신설했습니다.
- "풍요롭고 행복한 한가위 특별 혜택..." 같은 멘트를 각 현장 특성에 맞춰 자유롭게 입력할 수 있습니다. (HTML 태그도 지원합니다)

### 2. 랜딩 페이지 (`index.html`) 렌더링 방식 변경
- **(Before)** 페이지 최상단에 고정되어 있어, 어떤 현장을 클릭하든 똑같은 멘트가 보였습니다.
- **(After)** 
  - 처음 진입 시에는 "진행 중인 이벤트 및 공동구매 목록"이라는 깔끔한 범용 안내 문구만 보입니다.
  - 고객이 특정 아파트 카드를 클릭하여 폼을 펼치면, **기존의 범용 문구는 숨김 처리되고, 해당 이벤트용으로 셋팅된 [도입 문구]가 메인 상품 바로 위에 크게 노출됩니다.**
  - 만약 관리자 페이지에서 도입 문구를 비워두면, 기존처럼 "여름철 눅눅한 욕실, 언제까지 방치하시겠습니까?"가 기본값으로 뜹니다.

### 3. AI 에이전트 전용 "이벤트 등록 워크플로우" 학습 완료
- 향후 매주 진행되는 이벤트 등록 과정에서 AI가 구조를 착각하지 않도록, `detail-page-maker` 스킬(매뉴얼)에 **(a)~(d)의 페이지 구조 및 이벤트 세팅 순서**를 강제 규칙으로 명문화했습니다.
- 이제 "전단지 현장 등록해줘"라고 명령하시면, AI가 이 구조를 정확히 인지하고 데이터 세팅을 신속하게 돕습니다.

## 🌐 라이브 서버 배포 완료
모든 코드는 `firebase deploy` 명령어를 통해 라이브 서버(`https://flyer-event-page-2026.web.app`)에 적용 완료되었습니다! 

관리자 페이지에 접속하셔서 **[이벤트 관리] 탭**에서 도입 문구를 작성해 보시고, 실제 폰(랜딩페이지)에서 클릭 시 의도대로 문구가 뜨는지 확인해 주시면 됩니다!
