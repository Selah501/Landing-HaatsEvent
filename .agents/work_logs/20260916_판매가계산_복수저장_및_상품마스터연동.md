# 🎯 판매가 계산 및 상품 마스터 연동 개선 워크스루

대표님께서 지시하신 요구사항에 맞춰 **판매가 계산기**와 **상품 마스터** 간의 데이터 구조를 완벽하게 통일시키고, 복수 판매가 저장 및 연동 기능을 배포 완료했습니다.

## 🛠️ 주요 변경 사항
### 1. 판매가 계산기 (price_calculator.html) 개선
- **DB 스키마 우회 저장 (안전성 확보)**:
  - 별도의 DB 컬럼 추가 작업 없이, 기존에 있던 `details` 컬럼(JSONB) 내부의 `price_histories` 배열을 활용해 견적을 안전하게 저장하도록 로직을 구현했습니다. 
- **복수 판매가 저장 & 관리 로직 완벽 구현**:
  - 한 제품당 **최대 4개**의 판매가 이력을 영구적으로 저장하고 불러올 수 있습니다.
  - 내역의 이름은 요청하신 대로 **[상품명_최종금액]** 형태로 통일되었습니다. *(예: 허리케인 HRH-90S_330,000원)*
  - 제품을 선택하면 화면 하단에 **해당 제품 전용 판매가 목록**이 렌더링됩니다.
  - **[🔄 불러오기 및 수정]** 버튼을 누르면 체크했던 옵션, 카테고리, 조정 금액 등이 예전 그대로 복원됩니다.
  - 불러온 견적을 수정하면 **[💾 새로운 판매가로 저장]** 하거나 기존 내역을 **[현재 내역 덮어쓰기]**, 또는 **[이 내역 삭제]** 할 수 있습니다.

### 2. 상품 마스터 연동 (product_master.html)
- **금액 항목 일치화**: 
  - 상품 마스터의 금액 입력 칸을 판매가 계산기와 정확히 일치시켰습니다:
  - **`매입가` → `제품원가`**
  - **`설치비` → `기본설치비`**
  - **`옵션/기타` → `옵션 비용` 및 `기타(조정금액)`** 
  - **`합계` (관리자 최종조정 반영됨)**
- **🚀 상품마스터에 적용 로직 (원클릭 세팅)**:
  - 판매가 계산기의 특정 내역 항목에서 **[🚀 상품마스터에 적용]** 버튼을 누르면 새 탭이 열리며 상품 마스터로 이동합니다.
  - 이때 백그라운드에서 선택한 견적의 **제품원가, 기본설치비, 옵션비, 최종금액** 등의 상세 데이터를 가지고 넘어가며, 상품 마스터 페이지 진입 즉시 **해당 제품의 수정 모달창이 스르륵 열리고 모든 금액이 자동으로 채워집니다.**
  - 대표님께서는 금액이 맞는지 최종 확인하신 후 **[저장]**만 누르시면 실제 적용이 완료됩니다!

## 🧪 테스트 방법
1. 브라우저에서 새로고침 후 판매가 계산기에 들어갑니다.
2. 특정 제품을 선택하고 임의로 금액과 옵션을 만진 뒤 **[새로운 판매가로 저장]**을 2~3회 반복해 봅니다.
3. 하단에 저장된 리스트에서 하나를 골라 **[🔄 불러오기 및 수정]**을 누르고 값들이 그대로 복구되는지 확인합니다.
4. 마지막으로 해당 내역의 **[🚀 상품마스터에 적용]** 버튼을 눌러, 팝업이 뜨고 금액이 제대로 박혀 있는지 확인 후 저장해보세요.

> [!NOTE]
> 롤백 대비 및 백업이 모두 고려되어 작성되었으며, 해당 기능은 라이브 호스팅에 즉시 배포(`firebase deploy --only hosting`) 되었습니다. 바로 실무에 활용하셔도 좋습니다!
