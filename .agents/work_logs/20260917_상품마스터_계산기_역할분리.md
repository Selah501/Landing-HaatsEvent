# 🛒 상품마스터 ↔ 계산기 워크플로우 분리 완료

상품 마스터와 판매가 계산기의 역할을 완전히 분리하여, 데이터가 꼬이거나 원가가 0원으로 덮어씌워지는 위험 요소를 원천 차단했습니다.

## 🛠️ 변경 및 개선 사항

1. **역할의 완전한 분리**
   - **상품 마스터**: 순수하게 "새로운 상품을 등록하고 제품 고유의 원가를 입력하는 명부"로 역할 제한.
   - **판매가 계산기**: "고객에게 보여줄 견적과 최종 판매가를 결정하는 공간"으로 역할 부여.

2. **상품 마스터 모달 UI 컴팩트화**
   - 기존에 너무 넓고 입력 가능해 보였던 영역을 **하나의 단일 박스**로 깔끔하게 묶었습니다.
   - 수정할 수 있는 항목은 오직 **[제품 원가]** 한 개뿐입니다.
   - 기본설치비, 옵션비용, 기타, 합계 금액 등은 **단순 텍스트(읽기 전용)**로 작게 렌더링되도록 수정했습니다.

3. **판매가 세팅 바로가기 연동**
   - 상품 마스터에서 가격 박스 상단에 **`[이 상품의 판매가 세팅하러 가기 ↗]`** 버튼을 신설했습니다. 버튼 클릭 시 판매가 계산기로 즉시 이동합니다.

4. **과거 저장된 복수 견적 렌더링**
   - 계산기에서 여러 개의 판매가 버전을 저장해둔 경우, **상품 마스터 모달 하단(가격 정보 박스 안)에서도 해당 견적들의 리스트(최대 4개)를 확인**할 수 있도록 추가했습니다.

> [!TIP]
> 이제 상품 마스터에서는 이름, 이미지, 기본 원가만 적어두시고, 가격 고민이나 조율은 `판매가 계산기`에 가셔서 편하게 여러 버전으로 저장하시면 됩니다!

## 🧪 테스트 방법
1. 호스팅된 웹앱을 새로고침(F5) 합니다.
2. 상품 마스터에서 아무 상품이나 [상세/수정] 버튼을 클릭해 봅니다.
3. [제품 원가] 필드만 입력 가능하고, 하단에 저장된 판매가 내역이 노출되는지 확인합니다.
4. `[이 상품의 판매가 세팅하러 가기 ↗]` 버튼을 눌러 계산기가 정상적으로 열리는지 체크합니다.
