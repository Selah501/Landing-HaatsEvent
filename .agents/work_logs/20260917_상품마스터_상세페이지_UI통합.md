# 20260917 상품마스터 상세페이지 및 외부링크 관리 UI 통합 개편

## 1. 개요
* **목적**: `product_master.html` 내에 분리되어 있던 "제품 이미지 1, 2, 3" 입력란과 "AI 상세페이지 보관함"을 하나의 통일된 리스트로 묶어 관리 편의성을 극대화.
* **배경**: 이벤트 현장관리(`admin.html`)에서는 하나로 통합된 리스트를 제공하는데 반해, 상품마스터는 UI가 분리되어 있고, 특히 외부 링크(제품 이미지)는 삭제 버튼이 없어 빈칸으로 지워야 하는 등 관리가 어려웠음.
* **리스크 관리**: DB 구조 변경 시 발생할 수 있는 데이터 유실 및 부작용을 방지하기 위해 DB 스키마(`detail_urls`, `detail_pages`)는 기존 그대로 유지하고, 오직 화면에 노출되는 **프론트엔드 UI/UX만 통합**하는 방식으로 안전하게 진행. 개편 직전 Git 롤백 지점 생성 완료.

## 2. 주요 개선 사항
### A. "제품 이미지 1, 2, 3" 텍스트 입력 UI 폐지
* 제한적이고 관리가 어렵던 고정 3칸 텍스트 인풋을 삭제.
* URL을 입력하고 **[+ 외부 링크 추가]** 버튼을 누르는 즉각적인 추가 인터페이스로 개편.
* 링크 개수(3개) 제한 해제.

### B. [상세페이지 리스트 (통합 보관함)] 신설
* 기존의 AI 상세페이지 보관함 영역을 확장하여, 외부 링크(`detail_urls`)와 AI 상세페이지(`detail_pages`)가 **하나의 통일된 리스트**에 렌더링되도록 수정.
* 리스트에 노출되는 네이밍 룰을 이벤트 현장관리(`admin.html`)와 완벽하게 100% 동기화 (예: `🔗 이미지 원본 1`, `📄 AI 생성 버전 (26.09.08)` 등).

### C. 기능 일원화 (미리보기 및 삭제)
* 통합 보관함 내 모든 항목에 대해 일관된 **[미리보기]**, **[삭제]** 버튼 제공.
* **안전한 저장 로직**: 
  * AI 버전을 제외한 '외부 링크' 편집 내역(추가/삭제)은 메모리(`currentDetailUrls`)에만 보관되다가, 최하단의 **초록색 [저장] 버튼**을 누를 때만 DB(`products.detail_urls`)에 반영되도록 기존 동작 룰을 그대로 유지하여 실수로 인한 데이터 삭제 방지.

## 3. 결과 및 검증
* Firebase Hosting 배포 완료. (`flyer-event-page-2026.web.app`)
* 상품마스터 모달 호출 시 에러 없이 부드럽게 통합 리스트가 렌더링되며, 이벤트 모달창의 드롭다운과 이질감 없이 완전히 융화됨.
