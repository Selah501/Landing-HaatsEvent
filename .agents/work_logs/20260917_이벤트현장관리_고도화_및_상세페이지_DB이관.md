# 20260917 이벤트 현장관리(admin) 상품등록 고도화 및 상세페이지 마이그레이션

## 1. 개요
* **목적**: `admin.html` 현장 이벤트 관리 모달에서 메인/부가 상품 등록 시 단가와 상세링크를 수동 입력하던 불편함 개선.
* **주요 성과**: 상품 선택 시 마스터 DB에 저장된 단가(단수정리 포함)와 최신 상세페이지가 자동 입력 및 드롭다운 선택 가능하도록 전면 개편. 흩어져있던 10개의 구형 상세페이지(HTML) DB 일괄 이관.

## 2. 세부 작업 내역
### A. 단수정리 오류 완벽 연동
* **문제**: `price_calculator.html`에서 5천원 단위 단수정리를 해도 `product_master`에 넘기면 원가+시공비 단순 합산으로 재계산되어 단수정리가 풀리는 버그 발생.
* **조치**: 단수정리로 인한 차액을 `prices.other`(기타 조정) 필드로 역계산하여 반영. 결과적으로 상품마스터의 최종 판매가(`sell_total`)가 견적기의 단수정리 금액과 완벽히 일치하도록 수정.

### B. 로컬 상세페이지 DB 마이그레이션 (10건)
* **대상**: `public/products/` 폴더에 방치되거나 누락된 10개 구형 `.html` 파일 (제로크, 테라, 티오람 미니 등).
* **조치**: 10개 파일의 코드를 파싱하여 Supabase `products` 테이블 내 각 상품의 `detail_pages` 항목(JSONB)으로 100% 이관.
* **효과**: 기존 물리 파일 의존을 끊고 상품마스터 모달 내에서 모든 상세페이지(AI버전 + 구형버전)를 직접 미리보기/삭제 관리 가능해짐.

### C. 현장관리 모달(admin) UI 최적화
* **자동 입력**: 메인/부가 상품 선택 시 단수정리된 `기본 판매가`와 `최신 상세페이지 링크` 자동 입력.
* **드롭다운 개선**:
    * **단가**: 불필요한 원가/시공비를 숨기고 `기본 판매가` 및 과거 계산기로 저장한 `견적가` 리스트만 노출.
    * **상세링크**: 길고 복잡한 URL 대신 `📄 AI 생성 버전 (26.09.08)`, `📄 구형 병합본` 등 직관적인 텍스트와 생성일 표기 적용 (중복 필터링 적용).
* **미리보기 연동**: 모달 내에서 선택한 상세페이지를 즉각 확인할 수 있는 [미리보기] 버튼 신설.

### D. AI 에이전트(detail-page-maker) 규칙 강화
* `SKILL.md` 업데이트: "상세페이지 생성 시 무조건 상품마스터 DB(`detail_pages`)에 바로 저장하고, 제목은 `AI 생성 버전 (YY.MM.DD)` 포맷을 강제할 것" 명시.
