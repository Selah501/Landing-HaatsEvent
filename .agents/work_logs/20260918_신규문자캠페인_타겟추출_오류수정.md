# 신규문자캠페인 타겟추출 검색 오류 수정 (V2 구조 호환)

## 작업 개요
- **이슈:** `admin.html`의 4번 탭(고객디비 문자발송)에서 "경남" 등 현장 키워드 검색 시 타겟이 0건으로 추출되는 버그 발생.
- **원인:** 문자발송 타겟 추출 함수(`extractCustomersForSms`)가 과거 V1 예약 시스템의 스키마(`res.address`, `res.cart`)만 참조하고 있었음. 최근 V2로 업그레이드되면서 고객 정보가 `customerInfo.apt`, `customerInfo.phone` 및 `report.usedProducts` 등의 새로운 JSON 스키마 구조로 저장되기 시작했는데, 이를 인식하지 못해 키워드를 찾지 못함.

## 주요 변경 사항 (`admin.html`)
1. **시공완료 스캔(Reservations) 데이터 호환:**
   - 기존 `res.address`뿐만 아니라 `res.customerInfo.apt`, `res.title`에서도 키워드를 검색하도록 개선.
   - 제품명(detailProducts) 표기 시, V1의 `cart`뿐만 아니라 V2의 `report.usedProducts`, `customerInfo.products` 데이터도 호환되도록 추출 방식 고도화.
2. **상담/보류 스캔 스키마 버그 2종 수정:**
   - **(A) 일반 상담접수(`consultations`) 누락 수정**: 구형 데이터에 사용되는 `apartment`, `adminMemo`, `eventName` 필드를 스캔 기준에서 누락했음을 확인하여 추가 보완 조치 (예: '내포 모아엘가 핫썸머' 건 등 누락 방지). 
   - **(B) AI 상담리드(`crm_pending`) 구조 오류 수정**: 기존 코드에서 주석은 '상담보류 스캔'이라고 되어 있었으나 실제로는 `currentConsultations`만 순회하고, 최근 도입된 `currentCrmPending`을 누락하는 문제가 있어 추가함. 더불어 데이터 구조가 날짜별로 묶이지 않은 평면 구조(Flat)임에도 이중 반복문으로 스캔하던 버그를 해결.
3. **입력 키워드 스마트 파싱(따옴표, 복수 단어 지원):**
   - 대표님께서 예시 문구인 `""경남" 또는 "경남아너스""`를 그대로 입력하셨을 때, 통째로 하나의 단어로 인식하여 검색결과가 0건이 나오는 현상을 방지.
   - 불필요한 따옴표(`"`, `'`)를 자동 제거하고, `또는`, `,`, 띄어쓰기 등으로 단어를 분리해 여러 개의 키워드로 동시 스캔(or 검색)하도록 개선.
4. **Firebase 라이브 배포 완료 (`firebase deploy --only hosting`)**

## 결과 확인
- 이제 "경남", "내포" 등의 키워드로 검색 시, V2 시스템을 통해 접수된 최신 시공 완료건 및 보류/상담 건들이 모두 정상적으로 추출되어 문자 캠페인 목록에 담깁니다.
