# 테라 및 허리케인 상세페이지 추석 이벤트 셋업 (2026.09.18)

## 1. 작업 개요
- **목표:** 기존 추석 이벤트 테라 후드 상세페이지의 안내 문구 수정 및 허리케인 후드(HRH-90S)의 상세페이지를 동일한 이벤트 템플릿(어두운 테마)으로 신규 생성.
- **수행자:** AI (Antigravity)

## 2. 세부 변경 사항

### [1] 테라 상세페이지 파일 수정 (`chuseok-terra.html`)
- **수정 위치:** `landing/public/products/chuseok-terra.html`
- **전문시공 영역 추가:** 본사 공식 대리점의 전문 시공 섹션에 `✓ 이전설치와 폐기수거가 포함된 이벤트 가격` 뱃지 추가.
- **안내사항(CS 방어) 영역 수정:** 기존 '설치비용에는 다음 모두 포함된 가격입니다...' 텍스트를 모두 삭제하고 빈칸으로 깔끔하게 비움.

### [2] 허리케인 후드 상세페이지 생성 및 DB 마이그레이션 적용
- **데이터 처리:** 로컬 HTML 파일을 새로 생성하지 않고, `SKILL.md` 가이드에 따라 **Supabase 상품 마스터 DB (`products` 테이블, `detail_pages` 항목)** 에 템플릿 적용본을 주입함.
- **템플릿 적용 내역:** 테라의 이벤트 템플릿을 기반으로 아래 항목 치환:
  - 가격: 기존가 355,000원 ➔ **혜택가 335,000원**
  - 사은품: **추석맞이 특별 혜택 기름받이 무료 증정** 문구 반영
  - 이미지: 기존 DB에 연동되어 있던 허리케인용 카탈로그 이미지(`catalog.png`, `install.png` 등)로 교체 매핑.
- **버전 기록:** 관리자 모달에서 확인할 수 있도록 `AI 생성 버전 (26.09.18)` 이라는 타이틀로 신규 버전 삽입 후 활성화(`is_active: true`).

## 3. 배포 현황
- **Firebase Hosting 배포 완료 (`firebase deploy --only hosting`)**
- 테라 페이지는 기존 URL 그대로 실시간 반영되었으며, 허리케인 페이지는 앱 내 제품 상세 뷰(`product.html?id=...`) 렌더링 시 최신 이벤트 템플릿으로 출력됨.
