# 문자 캠페인 발송 링크 신규 도메인(haatz.shop) 교체

## 작업 개요
- **일시:** 2026-09-20
- **목적:** 홈페이지 전면 개편(추석 연휴)에 앞서, 당장 내일 인쇄할 신규 전단지와 문자 캠페인 영업에 새 도메인(`haatz.shop`)을 활용하기 위함.
- **주요 내용:** 기존 `flyer-event-page-2026.web.app` 대신, 4번 탭에서 문자를 발송할 때 `https://haatz.shop` 링크가 찍히도록 프론트엔드 코드 수정.

## 주요 변경 사항 (`admin.html`)
1. **SMS URL 하드코딩 교체**
   - 기존 `window.location.origin`을 참조하여 동적으로 링크를 생성하던 로직을 수정.
   - `const baseUrl = 'https://haatz.shop';` 으로 고정하여 어떠한 환경(테스트 등)에서 발송해도 고객에게는 새 공식 도메인이 전송되도록 처리.
2. **하위 호환성 검토 완료**
   - Firebase Hosting 다중 도메인 정책에 따라 구형 링크(`flyer-event-page...`)가 삽입된 기 배포 전단지는 정상 유지.
3. **라이브 배포**
   - `firebase deploy --only hosting` 완료.

## 후속 작업 대기 (대표님 실행)
- Firebase 콘솔에서 `haatz.shop` 커스텀 도메인 추가 후 DNS(네임서버) TXT/A 레코드 연동 필요.
