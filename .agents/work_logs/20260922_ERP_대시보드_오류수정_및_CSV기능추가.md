# 🚀 2026-09-22 작업 요약: ERP 대시보드 실적 집계 정상화 및 CSV 다운로드 기능 추가

## 📌 배경 및 문제 상황
- 8월, 9월 재무장부 대시보드에서 매출 및 순이익이 부풀려져 나오는 문제가 발생했습니다.
- 원인 분석 결과, `admin_v2.html`에서 작업보고서를 수정(재결재)할 때마다 과거 매출이 장부(`ledger`)에 무한 중복으로 푸시되는 로직 버그가 있었습니다.
- 현장의 마스터 DB(단가 정보)가 완벽히 정비되지 않아, 과거 장부에 의존할 경우 점진적 데이터 정비에 대응하지 못하는 구조적 한계가 있었습니다.
- 대표님의 요청: "현장 지장 없이 가장 안전한 방식으로 신뢰성을 회복하고, 일별 매출/지출 내역을 구글 시트 형식으로 다운로드할 수 있게 할 것."

## 🛠️ 해결 방안 및 구현 내용

### 1. `admin_v2.html` (현장 보고서 수정 시 중복 방지)
- 장부에 `income` 데이터를 push하는 조건문에 `isFirstCompletion` 조건을 추가하여, 최초 결재 시에만 장부에 기록되도록 수정했습니다.
- **안전성:** 기존 화면 UI 및 저장 방식(원클릭 병합)은 전혀 건드리지 않아 현장 작업자에게 영향을 주지 않습니다.

### 2. `erp.html` (대시보드 신뢰성 회복 및 CSV 내보내기)
- **`updateDashboardStats()` 전면 개편:**
  - 꼬여있는 과거 장부를 무시하고, 실제 결재된 **`reservations` (작업지시서) 데이터를 기준으로 매출과 원가를 1회씩만 집계**하도록 변경했습니다.
  - 매출원가(COGS) 계산 시 과거 가격이 누락되어도 최신 상품 마스터 DB 단가를 동적으로 불러와 계산하도록 개선하여, 추후 구글 시트를 정비할수록 과거 대시보드 수치도 정확해지는 유연한 구조를 마련했습니다.
  - 순수 수동 지출(경비) 및 기타 수입은 기존처럼 `ledger`에서 필터링하여 합산합니다.
- **출고 장부(탭 3) 중복 표기 버그 수정 (`renderSalesLedger`):**
  - 여러 슬롯(예: 4슬롯)을 차지하는 작업의 부품들이 슬롯 수만큼 중복으로 리스팅되던 현상을 `reservationId` 기준으로 deduplication 처리하여 1건당 1회씩만 표기되도록 수정했습니다.
- **CSV 다운로드 기능 추가 (`exportDashboardToCSV`):**
  - 탭 1 실적 필터 옆에 `📥 엑셀(CSV) 다운로드` 버튼을 배치했습니다.
  - 선택한 기간 동안 매출 혹은 지출이 있는 날짜별로 `날짜`, `총매출`, `매출원가`, `지출`, `순이익`, `적요(메모)`를 합산하여 UTF-8 BOM 인코딩 기반의 엑셀 호환 CSV 파일로 즉시 다운로드합니다.

## ✅ 배포 및 마무리
- Firebase Hosting (`firebase deploy --only hosting`) 배포 완료.
- 대시보드의 실적이 실제 예약 내역과 100% 일치하며 중복 없이 정상 집계됨을 확인했습니다.
