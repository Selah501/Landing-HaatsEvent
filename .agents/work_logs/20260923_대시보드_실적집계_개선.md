# 대시보드 실적집계 화면 개선 작업 내역

대표님께서 요청하신 ERP 대시보드의 실적집계 항목 업데이트 작업이 모두 완료되어 라이브 서버에 반영되었습니다.

## 🛠 주요 수정 내용

1. **매출이익 항목 분리 (발생주의)**
   - 기존에는 총매출, 매출원가, 순이익만 표기되었으나, `총매출 - 매출원가 = 매출이익` 항목을 신규 통계 카드로 추가하여 렌더링하도록 변경했습니다.
   - 이를 통해 1차 마진(제품 시공 마진)을 더욱 직관적으로 확인할 수 있습니다.

2. **작업일수(%) 계산 고도화**
   - 현재 필터링된 기간(월, 분기, 연도 등)의 전체 일수를 자동으로 파악하여 백분율(%)로 변환하는 로직을 적용했습니다.
   - 예시: 8월(31일)로 필터 지정 시, `10 일 / 31 일 (32%)` 형태로 노출됩니다.

3. **일평균 지표 4분할 시각화**
   - 기존의 단일 '일평균 순이익' 카드를 확장하여 아래 4가지 지표를 한눈에 볼 수 있는 넓은 카드로 개편했습니다.
   - `[매출]`, `[매출이익]`, `[경비]`, `[순이익]`의 일평균 금액이 2줄 포맷으로 깔끔하게 정렬됩니다.

4. **CSV (엑셀) 추출 데이터 동기화**
   - 대시보드 화면 변경에 맞춰 엑셀 파일(CSV) 다운로드 시에도 매출이익 항목이 추가되도록 헤더와 데이터를 조정했습니다.
   - CSV 문서 최하단에 생성되는 요약본 역시 동일하게 4분할 일평균 지표가 기록됩니다.
