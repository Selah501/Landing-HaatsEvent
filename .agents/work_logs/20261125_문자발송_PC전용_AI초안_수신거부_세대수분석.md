# 2026-11-25 문자발송 PC 전용 개편 · AI 문구 초안 · 수신거부 · 세대수 분석 구현

## 1. 작업 개요
- 유료 문자 API 없이 **데스크탑(PC) 전용 운영**으로 문자발송(4번 탭) 워크플로우를 전면 개편하고, 모바일 발송 흐름은 홀딩함.
- 이벤트 등록 시 지역 머리말(`[내포]`, `[아산]` 등)을 강제하고, 이를 문자발송 타겟 범위(전체/지역/개별) 및 AI 문구 초안 생성에 연계함.

## 2. 주요 변경 사항
1. **AI 문구 초안 생성 Cloud Function (`landing/functions/index.js`)**
   - `exports.generateSmsDraft`: 발송 범위, 대상 지역, 대상 고객군, 발송 목적 개요를 바탕으로 Gemini(`gemini-2.5-flash`)가 도입문구·링크문구·맺음말 초안을 생성하며, 수신거부 안내 문구를 필수 결합해 반환.
2. **이벤트 등록 지역 머리말 강제 (`landing/public/admin.html`)**
   - `1. 이벤트 관리` 모달에 기존 지역 머리말 빠른 선택 버튼(`#ev-region-quick-btns`) 추가 및 저장 시 `[지역]` 머리말 필수 검증 적용.
3. **문자발송 타겟·AI초안·수신거부 피드백 (`landing/public/admin.html`)**
   - 타겟 범위 3단 확장(`🌐 전체 현장`, `📍 지역 지정`, `🏢 개별 현장`) 및 연결 랜딩페이지 선택(`홈`, `상시페이지`, `개별 이벤트`) 지원.
   - `🚫 수신거부 번호 관리` 모달(`/sms_opt_out`) 신설 및 DB 추출 시 자동 제외.
   - 저장 시 수신거부 안내 문구 필수 포함(`ensureSmsOptOutOutro`).
4. **PC 발송 대시보드 · 통계 · 아파트 세대수 대비 분석 (`landing/public/admin.html`)**
   - Supabase `apartment_specs`(`total_units`, `sales_count`) 로드 연동.
   - `[💻발송(PC)]` 대시보드에 총 발송대상, 시공/상담 비율, 지역별 분포, 아파트 DB 총 세대수 대비 침투율(%), 이전 발송 이력 요약 테이블 구현.
   - 10명 단위 그룹별 `[📋 번호 복사]`, `[📋 문자 본문 복사]`, `[✅ 발송완료 체크]` 제공.

## 3. 검증 및 배포
- `verify_sms_v2.js`로 Cloud Function 및 `admin.html` 구문 검사, 지역추출, 수신거부 필터/맺음말 강제, 아파트 DB 세대수 대비 분석 로직 검증 통과.
- `generateSmsDraft` Cloud Function 및 Firebase Hosting 배포 완료.
