# 2026-11-25 고객디비 문자발송 시공/상담 분류 및 제품명 검색 개선

## 1. 작업 배경
- `씽크볼` 등 특정 품목 관심 고객에게 이벤트 안내 문자를 발송할 때, 이미 해당 품목을 시공한 고객에게 또 시공 안내 문자가 발송되는 것을 방지하고, 시공고객(기존 고객 관리)과 상담고객(미시공 리드)을 분리해 맞춤 멘트로 발송할 수 있도록 개선함.
- 다른 대화창에서 예약 시스템 개선 작업이 병행 중이므로 공식 랜딩페이지 및 예약 파일은 건드리지 않고, `관리자 페이지 > 4. 고객디비 문자발송` 영역만 독립 수정함.

## 2. 주요 변경 사항 (`landing/public/admin.html`)
1. **시공완료 DB 제품명 검색 추가 (`getSmsReservationProducts`)**
   - 기존 주소·메모뿐만 아니라 `cart`, `report.usedProducts`, `customerInfo.products` 등 시공·예약 제품명까지 키워드로 검색되도록 보완.
2. **전화번호 정규화(`normalizeSmsPhone`) 기반 통합 중복 정리 및 교차 판별**
   - 하이픈 유무를 무시하고 숫자 기준으로 3개 DB(시공완료, 상담접수, AI 통화리드)의 중복 연락처를 하나로 병합.
   - 통화기록/상담내역에서 추출된 고객이라도 전체 시공완료 DB에 시공 이력이 존재하면 자동으로 `상담 후 시공함(시공고객)`으로 분류.
3. **3단 원클릭 선택 필터 UI 추가 (`selectSmsCategory`)**
   - `[☑️ 전체 선택]`, `[🔵 시공고객만 선택]`, `[🟠 상담고객만 선택]`, `[⬜ 전체 해제]` 버튼 및 카테고리별 인원 요약 표시 추가.
4. **기본 도입문구 범용화**
   - 기존 추석/주방후드 고정 문구를 범용 공동구매 이벤트 안내 문구로 변경.

## 3. 검증 결과
- Node.js 검증 스크립트(`verify_sms_extract.js`)로 `admin.html` 내 6개 스크립트 블록 구문 무결성 및 제품명 검색/중복정리/상담후시공 교차판별/3단 분류 선택 로직 테스트 통과.
