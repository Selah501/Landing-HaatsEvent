# 2026-11-25 상담신청 · 설치예약 동선 및 옵션·동시할인 개선

## 1. 주요 개선 사항
- **이벤트 메인 페이지 (`landing/public/index.html`)**
  - `👉 무료상담 신청` 클릭 시 인라인 폼으로 부드럽게 스크롤 이동(`scrollIntoView`) 적용.
  - 품목별 고객 선택 옵션(주방후드 전동댐퍼 `+88,000원`, 효성해링턴 등 특례 단지 `안방욕실 아크릴마감판 +30,000원`) 및 **동시신청 할인(2개 이상 시 추가 상품당 20,000원 할인)·예상 합계** 실시간 계산 표시.
  - 한국 로컬 날짜(KST) 기준 `consultations/{YYYY-MM-DD}` 저장으로 UTC 새벽 시간대 전날 저장 버그 수정.
  - 제출 완료 후 단지명(`apt-name`)이 지워지던 초기화 버그 수정 및 연락처 `010-` 기본값 복구.
- **상시 카탈로그 페이지 (`landing/public/catalog.html`)**
  - 상담 모달 연락처 입력칸 `010-` 기본값 및 10~11자리 하이픈 자동 포맷팅 적용.
  - 한국 로컬 날짜(KST) 기준 저장으로 통일.
- **설치예약 시스템 (`landing/public/reservation_v2.html`)**
  - 고객 예약 순서를 **① 시공 제품 선택 → ② 날짜 선택 → ③ 시간 선택 → ④ 연락처 및 동·호수 입력**으로 개편.
  - 선택한 제품 소요시간(`slotsNeeded`)에 따라 **연속 예약이 불가능한 시간대 자동 비활성화(`연속예약불가`)** 및 제품 변경 시 시간표 자동 재검증.
  - 선택 옵션·동시신청 할인·예상 합계 실시간 계산 및 접수 내역 반영.
  - 상단 `← 뒤로` 버튼을 원래 보고 있던 이벤트(`?event=...`)로 복귀하도록 연결하고, 제출 완료 후 동·호수 입력칸 초기화 버그 수정.

## 2. 병행 작업 충돌 방지
- 다른 대화창에서 수정 중이던 `landing/public/admin.html`(4번 탭 고객디비 문자발송 모달)은 일절 건드리지 않고, 기존 `consultations` / `reservations` 스키마 호환성을 100% 유지함.

## 3. 검증 및 배포
- `verify_html_js.mjs`를 통해 `index.html`, `catalog.html`, `reservation_v2.html`, `product_master.html`, `admin.html` 전체 `<script>` 문법 검증 통과.
- `firebase --project flyer-event-page-2026 deploy --only hosting` 실행으로 라이브 반영.

## 4. 추가 보완 (피드백 반영)
- **상품 마스터 (`landing/public/product_master.html`)**
  - 상단 **제품군별 소요시간 일괄 설정** 바 추가 (선택 제품군 일괄 분 입력 → Supabase `details.duration` 및 Firebase RTDB `/products` 즉시 동기화).
  - 테이블 `소요시간` 컬럼 및 개별 수정 모달 내 `⏱️ 시공 소요시간 (분)` 입력칸 추가 (일괄값·개별값 모두 지원 및 유지).
- **설치예약 시스템 (`landing/public/reservation_v2.html`)**
  - 관리자 패널에 `📱 고객·전화예약 플로우로 전환` ↔ `👑 관리자 일정관리 모드로 전환` 토글 추가 (`?eventId=` 진입 시 자동 고객·전화예약 플로우 시작).
  - 예상 작업 시간에 계산 근거 `(선택 합계 N분 · 60분 단위 올림)` 표기.
  - 날짜 선택 화면에 예약대기 및 담당자 검토·변경 협의 안내 문구 추가.
- **상시 카탈로그 페이지 (`landing/public/catalog.html`)**
  - 관리자 로그인(`adminAuth`) 또는 `?admin=1` 접속 시 상단 `⚙️ 관리자메인` 복귀 버튼 표시.
