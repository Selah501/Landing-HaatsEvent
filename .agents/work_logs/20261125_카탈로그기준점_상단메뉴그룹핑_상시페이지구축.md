# 2026-11-25 카탈로그 기준점 복구 · 상단 메뉴 3그룹화 · 상시 페이지 구축 요약

## 1. 작업 배경 및 원칙
- 다른 대화창에서 병행 중인 현장 오픈 작업과 충돌하지 않도록, 이벤트 데이터(`events`)와 임시 오픈 팝업은 건드리지 않고 **카탈로그 기준점 정리·관리자 메뉴 교통정리·상시 허브 신설**을 진행함.

## 2. 주요 완료 내역

### A. 0단계: 카탈로그 표준 이미지 기준점 확립 (Supabase `products`)
- **원인 규명:** 1차 초기 불량 크롭 폴더(`catalog_images/`)와 2차 4분면 표준 폴더(`images/catalog/`)가 공존하던 문제 확인.
- **표준 이미지 연결 완료 (5건):**
  - `테라 (DTR-90MS(P))`: 1차 불량 이미지(`DTR-90MSCI.png`) 제거 → 2차 표준(`images/catalog/deco_page_22_top_right.png`)으로 `detail_urls` 및 `detail_pages` 내부 URL 교체.
  - `허리케인 스노우 (HSH-90WHCI)`: `images/catalog/deco_page_21_top_left.png` 연결.
  - `씽크볼 수전 폰테 210 3WAY (FC TS100)`: `images/catalog/catalog_하츠_수전빌트인_p77_2.png` 연결.
  - `사각씽크볼 8502세트 (HZ-EW8502SF)`: `images/catalog/catalog_하츠_씽크볼_p83_1.png` 추가 연결.
  - `허리케인 (HRH-90S)`: 구형 1차 이미지(`HRH-90S.png`) 링크 제거.
- **중요 펜딩 분류 (`HISTORY_AND_ROADMAP.md`, `PENDING_IDEAS.md`):**
  - 하츠 환풍기 2종(`티오람 미니`, `티오람G`) 및 타사 힘펠 5종은 현재 더미/기존 이미지로 유지하며, 타사 카탈로그 내부 형태가 다름을 반영해 별도 포맷으로 추후 신중히 처리하기로 기록.

### B. 관리자 상단 통합 메뉴(GNB) 3그룹 시각적 정리 (`landing/public/auth.js`)
- 기존 11개 평면 나열 버튼을 **`현장·현업` / `상품·자료` / `통제·고객`** 3개 라벨 그룹으로 묶고, **`🛍️ 상시페이지`** 바로가기 버튼을 추가해 화면 혼란을 해소함.

### C. 기간 무관 '상시 페이지' 구축 (`landing/public/catalog.html` & `index.html`)
- 이벤트 기간 종료 후에도 QR/문자 링크 저장 고객이 언제든 접속해 **활성 제품 목록, 시공 포함 기준가, 상세 스펙, 최신 카드 무이자 할부, 간편 상담 신청(RTDB `consultations` + Google Apps Script 연동)**을 이용할 수 있는 상시 허브 신설.
- `index.html` 상단 버튼 영역에 `🛍️ 전체 제품 상시 안내 →` 진입 버튼을 추가함.
